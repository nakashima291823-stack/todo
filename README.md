# TODO

ブラウザだけで動くシンプルなTODOアプリです。ビルドや依存パッケージは不要です。

## 使い方

`index.html` をブラウザで開くだけで動きます。

- 入力欄に入力して Enter（または「追加」）でタスクを追加
- チェックボックスで完了／未完了を切り替え
- タスク名をダブルクリックで編集（Enterで確定、Escでキャンセル、空にすると削除）
- 「×」でタスクを削除
- 「すべて / 未完了 / 完了」で表示を絞り込み
- 「完了済みを削除」で完了したタスクをまとめて削除

データはブラウザの `localStorage` に保存されるので、ページを閉じても残ります。

## ファイル構成

- `index.html` — 画面
- `style.css` — スタイル（ダークモード対応）
- `app.js` — ロジック
